# 01 · 新手试玩记录

> 视角：**没玩过这个游戏、也没读过这份代码的第一次玩家**。屏幕外的一切（源码、DevTools、日志）只用来度量，不用来替游戏解释自己——凡是「必须查源码才知道」的，一律记成教学缺口。

## 1. 怎么试的

- 从零存档开始，桌面 1280×800 与手机 393×852 各完整走一遍：开屏 → 世界 → 取泥 → 塑形 → 雕刻 → 上色 → 烧制 → 预览 → 结算 → 重试 → 地图 → 升级 → 说明。
- 探针 tools/minitool/probe/newbie_playthrough.mjs：13 个状态快照；每屏对屏幕上**可见文本**算「第一眼分」= 字号 × 文字占屏面积 × 对比度 × 强调系数 × 动效，同时测面板溢出（scrollHeight/clientHeight）、按钮裁切、小于 44px 的命中区、禁用但没有原因。
- 诚实性说明：截图里瓷瓶轮廓崩坏是自动探针高强度拖动造成的**操作产物**，不是游戏缺陷。本文所有结论只引用布局、视觉层级、文案、可达性与实测数值。

## 4. 新手每屏都在问的三句话

1. **我在哪、进行到第几步？**
2. **这一屏唯一要做的事是什么、点哪里？**
3. **我做的东西算不算过关、差在哪、接下来怎么办？**

现状：第 1 问只有一行 12px 小字；第 2 问靠猜；第 3 问被折叠或根本不存在。

## 5. 结论

问题不在美术，也不在「界面太复杂需要简化」。问题是**信息权力分配反了**：装饰、奖励与世界观说明占走了最大字号和最大面积，而操作按钮与判断依据被压成 12–14px 或被折叠。所以重构的目标不是删东西，而是**重新分权**——详见 02-redesign.md 与可点原型 mockup.html。
