## 2. 设计落到屏幕上的三件事

**A. 每屏只有一个「现在要做这个」。**
世界屏右栏不再平铺 8 个模块：场景页签、三个关卡缩略、贴画、藏品按 order 排到任务板之后，参考卡压成 64px 缩略图一行。任务板给出一句话目标 + 46–48px 实心 CTA（「去取泥台 →」）+ 取泥/塑形/上色/烧制/交付五步进度，随状态自动推进，不需要玩家自己拼流程。

**B. 流程与判断依据放在做决定的那一刻。**
制作面板顶部五段步骤条（哪步已完成/正在做）；预览屏只给三条自查，不给任何分数；结算屏按顺序给：分数 → 形状/上色得分·权重·丢分表（主差高亮）→ 一句诊断 → 硬币规则 → 通过线。失败时主按钮直接变「领新瓷泥，再试一次 →」，一次点击回到可操作状态。

**C. 不靠「必须查源码」才懂。**
工位名字常显（数字钉退役）；顶栏 ⌖ / ↑ 补「地图」「升级」文字；禁用按钮补原因；页脚原型水印「四方瓷韵 05」隐藏；镜头进场就把小岛摆到画面中间，玩家第一件事不再是滚轮放大。
