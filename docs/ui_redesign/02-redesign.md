# 02 · 界面重构方案（新手优先）

## 0. 一句话

**每屏只留一条主线，把「下一步」做成可点的东西，把判断依据放到玩家做决定的那一刻。**

## 1. 五条根因

| # | 根因 | 现场证据 |
|---|---|---|
| R1 | **没有「当前唯一任务」**：世界屏同时有 8 个同级模块抢注意力，第一眼分最高的是右栏说明文字 | 02 屏 7.35；右栏模板见 src/main.js:135 |
| R2 | **流程只存在于文案里**：取泥→塑形→雕刻→上色→烧制→交付这条线，只写在教程句子与面板小字里，屏幕上看不见进度 | 面板顶部只有「2 / 3 · 塑形与雕刻」 |
| R3 | **视觉权力给了装饰，没给操作**：主按钮 12–14px，标题 20–33px，订单缩略图 120px；CTA 是屏上最小的一块 | 各屏排行榜 |
| R4 | **一屏装不下**：813/600、730/475、910/560 的溢出方向恰好是主按钮与评分标准 | 探针 OVERFLOW / CLIPPED |
| R5 | **关键信息被折叠或不存在**：评分标准在折叠面板里、参考图在默认关闭的复选框里、价格根本不显示、禁用状态没有原因 | src/main.js:320-324、src/upgrades-view.js:16-21 |

## 2. 六条设计原则

- **P1 一屏一条主线。** 每屏恰好一个「现在要做的事」+ 一个主按钮（实心、≥44px 高、≥15px 字）。副操作一律描边或文字链。
- **P2 三级信息权力。** 主线（大字/实心块/主按钮）｜辅助（14–16px）｜背景（页脚、贴画、藏品、版本号）。任何时刻主线只允许一个，背景不得使用强调色。
- **P3「下一步」必须可点。** 世界里的引导标牌本身就是入口：点「前往取泥台」就走过去，键盘/摇杆仍然可用但**不是过关前提**。这条直接消灭 N3。
- **P4 先做对，再做好看。** 功能块占主轴（中央舞台 + 底部操作条），装饰退到边缘与二级抽屉。
- **P5 禁用必须给原因；数字必须带单位；标准必须常显。** 「钱不够」写「还差 120 币」，不是灰着不说。
- **P6 一套 IA，三档响应式。** 不维护两套界面，只换排布（见 §4）。

## 3. 新信息架构（全局层 + 7 屏）

**全局层**
- 顶栏（44px，手机 36px）：左「terra · 古窑民俗」；中「第 1 关 / 3」+ 5 段进度点；右「铜钱 0」+ **文字入口**「地图」「工坊」「菜单」（手机图标旁保留 12px 文字，不再让 ⌖ / ↑ / ⋯ 单独承担语义）。
- 底栏（桌面 32px，可折叠/8 秒淡出）：键位提示（WASD / F / Esc），手机隐藏。删除「四方瓷韵 05」原型水印。
- 全局浮层：下一步标牌（世界里）+ 教学气泡（一句话，最多 2 行，可「知道了」关掉）+ 保存提示（顶栏灰字 4 秒）。

| 屏 | 唯一目标 | 主按钮 | 次入口 | 退路 |
|---|---|---|---|---|
| 开屏 | 进工坊 | 「走进工坊 →」 | 「看介绍」（不阻塞） | — |
| 世界 | 去当前工位 | 下一步标牌上的「前往取泥台」 | 地图 / 订单 / 升级 / 藏品（二级抽屉） | — |
| 取泥 | 领一块泥 | 「领取瓷泥 →」 | 「看订单要求」 | × 回世界 |
| 制作（塑形/雕刻/上色） | 按这一单的要求改一处 | 「保存并离开 →」 | 参考图开关 / 撤销 / 工具大小 | × = 保存并离开 |
| 烧制 | 把火候稳在区间 | 「按住鼓风」（常按区 96px） | 「跳过（低分）」 | × 放弃本次 |
| 预览 | 自查是否达标 | 「提交评分 →」 | 「回去再改」 | × 回世界 |
| 结算 | 看懂差在哪 + 选下一步 | 「重新塑形 →」 | 「回工坊」 | × 回世界 |
| 地图 / 升级 / 帮助 | 单一目的 | 各 1 个 | — | 「返回」固定左上 |

## 4. 三档响应式（同一 IA）

| 断点 | 世界屏 | 制作面板 | 面板骨架 |
|---|---|---|---|
| ≥1100px 桌面 | 中央舞台 + 右侧 280px 竖条（订单行、5 段进度、主按钮、四个图标入口） | 左画布 62% / 右要求卡 38%，底部固定操作条 | 顶部步骤条 + 底部操作条 |
| 640–1099 平板/横屏手机 | 单栏舞台 + 顶部订单 chip + 底部主按钮 | 画布 100%，要求卡改为上滑抽屉 | 顶部步骤 + 底部 dock |
| <640px 竖屏手机 | 舞台占屏宽 ≥78%、垂直居中偏上；订单 chip 一行；摇杆 + 「操作」并排拇指区 | 画布 100%，工具 dock 贴底，要求卡 = 「?」浮层 | 顶部一行步骤 + 底部 dock |

## 5. 逐屏：现状 → 建议

### 5.1 世界屏（最大改动）

**现状**：小岛占视口宽 32%；右栏 8 个同级模块；工位只有数字钉；底部一条带锁的胶囊提示；两个灰按钮无原因。

**建议**
1. **进场自动取景（N13）**：进入场景按小岛包围盒自动 fit 到视口 70% 宽（手机 78%），构图居中偏上；只在「首次进入 / 切场景 / 点恢复视角」时触发；玩家手动缩放后记住比例，不再强抢。桌面端不再需要第一件事就是滚轮放大。
2. **下一步标牌**：小岛上空浮一块宣纸卡——「① 取泥台」+ 一句 12px 为什么 + **主按钮「前往取泥台」**（点击即走到台前并自动面向）。键盘 W 与摇杆依然可用；标牌随进度换文案（见 §6 状态机）。
3. **工位钉改名**：数字钉 → 名字胶囊（取泥/塑形/雕刻/上色/窑炉/交付）；已完成的打勾、当前目标实心青花蓝 + 呼吸描边、未解锁的描边 + 锁。只高亮一个。
4. **右栏从信息墙改成一条竖条**：顶部订单一行（32px 缩略图 + 「第 1 关 · 一抹青花罐」+ 「目标 80%」）；中间 5 段竖向进度（取泥·塑形·雕刻·上色·烧制，当前段高亮）；底部主按钮「查看订单」。**场景页签 01–04、三个关卡缩略、贴画 400 币、藏品**全部收进底部「工坊」抽屉与右上「菜单」，不再常驻（它们属于「以后」）。
5. **效率用时**：从每块面板顶部撤掉，改为订单行里一行 11px「剩余 04:46 · 达标 +20%」，只在世界屏与取泥/预览屏出现。
6. **禁用原因**：任何灰按钮旁用 11px 灰字写原因（「先完成本站三单」「还差 120 币」）。
7. **手机**：摇杆与「操作」并排（摇杆 96px、操作 72px，拇指区），订单 chip 一行，进场自动取景，键位底栏隐藏。

### 5.2 制作面板（塑形 / 雕刻 / 上色共用一套骨架）

**现状**：右侧一整面说明墙（7 段文字 + 3 个复选框 + 一个「查看升级预览」大按钮）；主按钮 14px；上色页 813/600，工具滑杆被裁；上色页没有参考图；手机端只剩标题和两个色点。

**建议骨架（三种工位完全一致，只换动词与工具）**
- 顶部 44px：「第 3 步 · 上色」五段步骤条（已完成实心、当前段实心+下划线、未来描边）+ 右侧「Esc 保存并离开」。
- 左：画布（自适应取景，作品占画布高 70%，不再要求玩家先缩放）；画布右上角 **参考图开关，默认开启**（N7）：显示订单参考缩略（112px），可拖动、可隐藏。
- 右（桌面）/ 上滑抽屉（手机）：**要求卡**只留 3 条，每条 14px + 勾选框（「圆润罐身」「中间一条宽蓝带」「其余留白」）；下一行「通过标准：提交后评分」（**不给任何分数与实时分项**，遵守需求）。
- 工具区：颜色（白瓷 / 青花，带**名字**，不只色点，N14）+ 工具大小滑杆 + 撤销/重做（图标 + 文字）。
- 底部固定操作条（始终在视口内，消灭 N8）：左小字「拖动即可上色 · Ctrl+Z 撤销」，右主按钮「保存并离开 →」≥44px。
- 说明文字：把「这里只能绘画，切去瓷泥请去雕刻台」这类**跨工位解释**收进「?」浮层，不再常驻正文。

### 5.3 预览屏

**现状**：两张图 + 「提交评分 →」（14px），无判断依据。

**建议**：你的作品 / 订单参考 左右对照（等大、同一背景），中间一张**自查清单**（勾选式，不是分数）：
- 轮廓是否接近订单（对照阴影边缘）
- 蓝色横带位置是否在腰部、宽度是否一致
- 其余是否留白

主按钮「提交评分 →」；次按钮「回去再改」。顶部一行「提交后按 形状 + 上色 评分，达到 80% 通过」——**只给规则，不给分数**。

### 5.4 结算屏（第二优先）

**现状**：23.1% 大字 + 「再完善一点」+ 「+0 硬币」；分项与标准折叠在详情里，展开溢出 255px；主按钮「再试一次」回到订单说明。

**建议**
- 首屏三件事：① 大数字 23.1% + 朱砂框「未通过 · 需 80% · 还差 56.9%」；② **两行评分条常显**（形状 65% / 上色 35%，各自分数 + 谁拖后腿打「主要差距」标）；③ 一句**可执行诊断**（由已有 state.result.shape/paint 比较得出，纯展示层，不改评分公式）：形状低 →「下次把罐身上半部收窄，蓝色横带留在中间」。
- 硬币行改成条件句：>0「本次 +34 币（满 60 分才有收益）」；=0「低于 60 分不产生收益」——不再出现无意义的「+0 硬币」。
- 主按钮 **「重新塑形 →」**（直接回取泥并保留进度），次按钮「回工坊」；Esc 提示保留。
- 折叠面板只留「本关完整标准」一项，默认展开前 3 行不溢出。

### 5.5 升级屏

**现状**：6 张卡只有 Lv 与效果，**没有价格**；余额 0；「确认升级」灰着不解释；说明写「悬停预览」，预览框空白；800/477。

**建议**：卡片三行——名称 + 「Lv.1 → 2」、一句效果、**价格「120 币」**；买不起时价格变灰 + 卡右下 11px「还差 120」。点卡选中后右侧详情（桌面）/底部抽屉（手机）写明「Lv.1 → Lv.2：白坯更大更圆」+ 主按钮「花 120 币升级」（禁用时按钮内文字就写原因）。顶部「当前余额 0 币」置顶常显。3D 预览若不可靠就先去掉，用一张静态示意图代替。

### 5.6 地图屏

**现状**：910/560，「重播地图开场 ↗」被裁；标题与地点同权重。

**建议**：地图占 60% 高、清晰标出「当前站（实心）」「已解锁（描边）」「未解锁（锁 + 条件文案）」；右栏/抽屉只放三行清单（三单 0/3、贴花 0/3、下一站条件）；主按钮「返回当前工坊」固定底部，永不溢出。

### 5.7 开屏 / 帮助

**建议**：开屏保留大标题与地方志轮播（用户明确要求不过度简化），只在底部加**一个**「走进工坊 →」主按钮 + 一行 12px「约 1 分钟，先看三句话」，把「看介绍」降级为文字链。帮助页把「01 目标 / 02 操作」压成 3 条 40 字以内的短句，操作按平台分两栏（桌面键盘 / 手机手势），并给出「现在就去取泥」的直达按钮。

|---|---|---|---|---|

## 7. 规范

| 项 | 规则 |
|---|---|
| 字号阶梯 | 大数字 40–56 / 屏标题 24–32 / 段标题 16–18 / 正文 14–15 / 辅助 12–13 / 最小 11（仅时间戳） |
| 命中区 | 所有可点元素 ≥44×44（手机 ≥48）；主按钮高度 ≥44，圆角 10 |
| 主按钮 | 每屏 ≤1 个实心青花蓝；其余描边或文字链 |
| 颜色 | 青花 #2B4C8C 主色；朱砂 #B4442F 仅未通过/警示；正文 #2A2723；次要 #8A8377；底 #FAF6EF |
| 对比度 | 正文 ≥4.5:1；#8A8377 on #FAF6EF ≈ 4.6:1 勉强达标，改动时须复测 |
| 禁用态 | 一律附原因文案（11–12px），不允许「灰了不说」 |
| 数字 | 必须带单位与标准（「23.1% / 需 80%」而非「23.1%」） |
| 文案模板 | 「做什么 + 为什么 + 点哪里」三句以内；删掉「这里只能…请去…」式跨工位解释（进「?」） |
| 动效 | 只用于引导（标牌呼吸、进度点亮），≤200ms，遵循 prefers-reduced-motion |
| 键盘/焦点 | Tab 顺序 = 视觉顺序；Esc = 返回；焦点环 2px 青花 |
| 手机手势 | 单指拖动 = 操作，单指拖空白 = 转视角，双指 = 缩放；摇杆与「操作」并排拇指区 |
| 溢出 | 任何面板在 1280×800 / 393×852 / 1024×768 三档都不得出现滚动才能点到主按钮（探针 OVERFLOW 必须为空） |

## 9. 刻意不做

- 不改评分公式、硬币数值、关卡数、6 工位流程（用户已定边界）。
- 不新增依赖、不重画美术资源、不改 3D 场景资产。
- 不在制作/预览屏显示任何分数或实时分项（用户明确要求）。
- 不为「高级感」再加装饰层——这一版的目标是把权力还给操作。
