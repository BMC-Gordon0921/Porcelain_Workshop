# Terra · 景德镇瓷器之旅

一个沿景德镇手绘地图展开的 Three.js 陶瓷工坊游戏。首页欣赏四件成品，自主选择观看地图介绍或直接进入工坊，沿四处地点各完成三单，购买贴画并贴到瓷碗上，最后收藏四件作品。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5174/。`npm run build` 生成生产版本；`npm run preview` 预览生产版本；`npm test` 运行游戏逻辑测试。

## 开场、声音与地图

首页展示青花、玲珑、窑变、粉彩四件 3D 成品。左右按钮和四个编号可以自主切换；拖动或画布上的方向键旋转模型。悬停、聚焦和拖动时暂停自转与轮播，离开后闲置满 5 秒淡出切换；后台暂停。减少动态效果模式关闭自转与淡入淡出。

点击“进入地图介绍”查看四站完整工坊与地标的实时 3D 全景，使用同样的轮播和旋转操作。展示使用独立预览实例，不改变存档、人物位置或工作台等级；离开时释放预览资源。点击“从古窑出发”“继续旅程”或按 Esc 进入当前进度，页面不会自行进入游戏。

背景音乐使用 `src/assets/pottery backround music.wav`。首次鼠标、键盘或触屏交互后，以 20% 音量循环播放，切换页面不会重头播放；页面隐藏时暂停。首页和游戏顶部的声音开关同步控制背景音乐与行走、制作、窑火等音效，开关偏好保存在本地。

游戏内“地图”和每站完成后的转场继续使用原始手绘路线图。未解锁的站点可以查看介绍，不能跳关。“重播地图开场”保留当前作品和进度。贴花后先保存下一站，再展示转场，刷新不会重复扣费或发奖。

## 第一单实操教学

新旅程第一站第一单按移动、取泥、塑形、雕刻、上色、烧制、交付的顺序强制引导，必须有实际操作才能推进。提示会高亮目标工作台和操作区域；可以继续完善作品、退出面板、打开玩法说明，刷新后恢复教学步骤。换泥会回到塑形步骤，撤销会恢复对应教学进度。

首次有效提交后结束教学，仍按正常 80% 标准评分。通过即计为第一单；未通过则自由重试同一订单，不再重复强制教学。教学不额外增加订单数。原有存档不强制补做教学。

## 评分与奖励

相似度 = 形状轮廓 IoU × 65% + 上色的平均颜色 F1 × 35%。每件作品须完成制胚、彩绘并烧窑后才可提交；烧成后仍可补绘，但不能退回制胚，补绘也不会改变已锁定的火候。下表为基础金币奖励，通关只按相似度判断。

| 相似度 | 硬币 | 本关结果 |
| --- | ---: | --- |
| 低于 60% | 0 | 重试 |
| 60% 至不足 70% | 60 | 重试 |
| 70% 至不足 80% | 70 | 重试 |
| 80% 至不足 90% | 80 | 通过 |
| 90% 至不足 100% | 90 | 通过 |
| 100% | 100 | 通过 |

常规收益 = 四舍五入（基础奖励 × 火候倍率 × 交付台倍率）。火候由 12 秒烧制中指针停留在火候带内的累计时间决定：完美秒数 + 成功秒数 × 0.5 占全程 ≥72% 为完美 ×1.25，≥38% 为成功 ×1.1，否则一般 ×1；窑炉二、三级分别再加 0.1、0.2。交付台三级分别为 ×1、×1.1、×1.2。

每次领取新坯开始效率计时，提交评分结束；有效用时不超过 **5 分钟（含 300,000 毫秒）**且达到 80%，再奖励四舍五入（常规收益 ×20%）。超时或未通过时效率奖励为零，原有收益全部保留。正式订单首次通关另得 **60 币**，练习不发首次奖励；这笔 60 币不参与倍率计算。结算逐项列出基础、火候、交付台、效率和首次通关奖励。

效率包含走路、制作、烧制及提交前查看作品的时间；帮助、地图、独立升级界面、页面隐藏和窗口失焦时暂停。关闭工作台回到工坊仍计时，但窑炉本身暂停。刷新保留累计时间，修改、撤销、重烧不会重置，重新领取白坯重新计时。

分数向下显示到小数点后一位，不会将 79.99% 显示为通过。未通过时重新领取瓷泥，已有硬币保留；同一件提交不能重复领奖。

## 四个场景与贴花

1. **古窑民俗博览区 → 青花缠枝纹 → 青花瓷碗**：第一张青花瓶的钴蓝花朵、藤蔓、双线边饰。
2. **中国陶瓷博物馆 → 玲珑白瓷纹 → 玲珑白瓷碗**：第二张白瓷杯的米粒状透光花瓣。
3. **御窑厂国家考古遗址公园 → 红金窑变纹 → 红金窑变碗**：第三张窑变瓶的金黄、朱红、深紫流釉。
4. **陶溪川文创街区 → 粉彩花瓣纹 → 粉彩花瓣碗**：第四张花形瓷器的粉色花瓣、细脉和绿萼。

每个场景完成三个正式订单：一抹青花罐、双环青花瓶、三点青花坛。贴画购买前可以任选五种设计进行练习，包括蓝沿瓷罐和青带月光罐；练习不增加正式通关数。【古窑手作坊】招牌后方保持留白，不再摆放陈列架，以免遮挡招牌与工坊视线。场景切换会改变工坊墙面、地面、光线、装饰盘和 UI 主题，并更换工坊后的立体地标：古窑砖窑与烟囱、博物馆现代展馆与青花大瓶、御窑红砖拱券与探方、陶溪川老厂房与文创摊位。建筑是依据地图意象制作的游戏化模型。六个工作台及行走通道保持可用。

- 完成本场景三关，**当前余额达到 400 币（含正好 400）**，即可购买该场景贴画。
- 每个场景购买一次，立即扣除 400 币；剩余余额带入下一场景。
- 在贴花台先选择贴画，再点击白瓷碗或“贴到碗上”。拖动模型可旋转查看。
- 贴花完成才可进入下一场景；第四件瓷碗完成后点击完成旅程，进入四件藏品总览。
- 三关通过后、购买贴画前，始终可以接练习订单。可用于补足升级或贴画费用；练习不增加通关数，仍可获得效率奖励。
- 藏品页可以再次打开每件作品的 3D 预览。

## 操作

WASD / 方向键移动；走近工作台按一下 F 操作；Esc 保存并退出面板。支持触摸控制。3D 工坊中按住鼠标左键拖动旋转视角，相机仰角限制为 0°—66°，不会低于水平面；滚轮缩放为 0.62—2.6 倍，点击“恢复视角”会平滑回到初始位置。面板打开时相机不响应输入。

- **取泥与订单**：领取白色瓷泥，升级后提供更接近目标轮廓的白坯；更换瓷泥只在这里进行。
- **粗塑成形**：从边缘推压或拉伸，默认显示目标轮廓、中轴线、口沿和底部线，默认左右对称，两者均可关闭。接近目标时轻辅助，单笔方向固定并限制极端位移；颜色随形变移动，拖回起点不产生撤销记录。
- **细节雕刻**：刻刀去除多余瓷泥，升级可开启轮廓保护。
- **手绘上色**：瓷白与钴蓝两种颜色，只改变已有表面；升级解锁直线笔及左右镜像绘制。
- **瓷器窑炉**：固定 12 秒连续烧制。按住空格或“按住鼓风”按钮升温，松开降温；让指针留在会缓慢漂移的完美／成功火候带内。系统累计完美秒数与成功秒数（成功按半秒折算），完美占比 ≥72% 为完美、≥38% 为成功，否则一般；倍率依次为 ×1.25、×1.1、×1。面板展示真实作品、窑火，工坊烟囱会持续冒烟，窑口在烧制时迸出火星；退出、帮助、后台或失焦时暂停，待机时炉门关闭。烧成后仍可补绘，但不能再制胚；补绘不会改火候。
- **评分与交付**：提交作品；完成三关后也可由这里进入贴花流程。

Ctrl/Cmd + Z 撤销本站最近一笔；Ctrl/Cmd + Shift + Z 重做；[ / ] 或滑块调整工具大小。

## 分场景升级

顶部“升级”可查看当地六个工作台，各台面板也提供入口。初始 Lv.1，升二级 30 币、升三级 60 币，满级后不能再购买。每个场景独立保存，金币在场景间保留。

| 工作台 | Lv.1 | Lv.2 | Lv.3 |
| --- | --- | --- | --- |
| 取泥 | 完整白坯 | 外轮廓靠近目标 30% | 靠近目标 50% |
| 塑形 | 1 像素内辅助 25% | 2 像素内辅助 40% | 3 像素内辅助 55% |
| 雕刻 | 连续刻刀 | 可保护目标内部，边缘容错 1 像素 | 可保护全部目标陶土 |
| 上色 | 连续画笔 | 增加直线笔 | 增加镜像，可与直线组合 |
| 窑炉 | 原倍率 | 倍率 +0.1 | 倍率 +0.2 |
| 交付 | 收益 ×1 | 收益 ×1.1 | 收益 ×1.2 |

取泥升级只影响下一块白坯，制作升级从下一笔生效；窑炉倍率在点火时锁定，本次烧制不受中途升级影响。标牌与器具细节随等级变化。

## 存档与资源

新版使用 v8 存档格式（沿用 `terra-porcelain-journey-v6` 键名以兼容旧档），保存在当前浏览器的 localStorage，并同步一份到 sessionStorage。刷新或重新打开相同地址后可继续；地址、端口或浏览器不同，存档独立。保存关卡、硬币、作品、贴画、藏品、四场景工作台等级、制胚／彩绘阶段、已完成火候和实际结算收入。效率用时每秒保存，并在暂停、提交、页面离开时同步保存。撤销历史和未完成窑炉计时不保存，刷新后重新烧制但保留效率用时。

自动迁移 v7、v6、v5 和 v4。旧档每站前三单算作正式通关，原第 4、5 单的历史记录和收益保留；正在制作的作品转为可选练习，没有领取瓷泥则进入贴画购买阶段。迁移保留金币、工作台升级、藏品和付费贴画，不补发奖励。教学状态和步骤也保存在 v8 存档中。v6 旧档保留既有火候等级与倍率；旧存档工作台默认一级，历史收入不重算、不补发首次通关奖励。旧档正在制作的作品没有可靠开始时间，本次不追溯效率奖励，下次领取新坯后开始。旧档已烧制但没有火候结果的作品按一般处理。

同一个浏览器标签页中的旧版 v4 存档会迁移到第一场景，保留关卡、硬币与瓷泥；旧版三关完成会进入贴画购买阶段。原 v4 存档键保留。

`public/maps/jingdezhen.png` 保存原始地图。`src/places.js` 维护四站地点、介绍及地图位置；`src/city-map.js` 负责首页、3D 场景介绍和游戏内路线界面；`src/landmarks.js` 构建各站立体地标。

`public/references/` 按顺序保存四张用户参考图。`src/decals.js` 以确定性的 Canvas 绘图重新设计四种环绕纹样，并生成 Three.js 贴图；不把照片背景或文字贴到瓷器上。`public/decals/` 提供四张 1024 × 512 PNG 导出版。这些纹样是依据参考图的风格重绘，玲珑效果通过釉色和高光表现，并非真实镂空。成品使用有内壁、口沿和圈足的 3D 碗模型。

原手作编辑仍是 112 × 112 的正面瓷泥表面，角色携带的模型对应实际编辑轮廓；不是体积陶泥模拟。游戏运行无需外部字体或图片服务。

## 验证

`npm test` 覆盖评分档位、80% 边界、失败发奖、400 币购买、重复操作、任务顺序与烧后补绘、四场景顺序、订单进度状态、贴花、成品收藏、v4—v8 存档恢复及原有手作工具行为。

`tests/progression.test.js` 另覆盖分场景升级、白坯辅助、对称与保护、固定 12 秒火候、按住鼓风、累计时间分级、倍率快照、五分钟精确边界、暂停策略及效率结算。`node tests/progression-browser.mjs` 验证真实鼠标／触摸拖动、升级、暂停、刷新恢复、按住空格鼓风与火候判定、中英文、效率收益及手机布局；截图输出到 `qa/progression/`。支持用 `GAME_URL` 指定已经启动的本地服务。

`tests/browser-smoke.mjs` 是可选浏览器检查，使用已安装的 playwright-core 和 Microsoft Edge。它使用独立浏览器上下文，在本地预览中检查领取瓷泥、移动、雕刻、真实柜台提交、四个场景购买与贴花、刷新恢复和窄屏布局，并将截图写入 `qa/`。不会写入日常浏览器的游戏存档。

`tests/map-browser.mjs` 检查首页等待按钮、手动进入地图、跳过与暂停、重播后保留作品、未解锁地图点不跳关、三次地图转场、四个地标、窄屏界面及减少动态效果模式。可用 `GAME_URL` 指定本地地址，`PLAYWRIGHT_MODULE` 指定已安装的 Playwright 模块；默认使用 Microsoft Edge，可用 `CHROME_CHANNEL` 改为其他已安装的浏览器通道。

`node tests/upgrade-browser.mjs` 检查首页轮播和悬停、相机边界与恢复视角动画、F 交互、塑形撤销、烧制暂停与存档、烧后补绘、触屏及中英文界面，截图写入 `qa/upgrade/`。运行浏览器检查前启动 `npm run dev`。

`node tests/journey-update-browser.mjs` 在隔离的 Edge 上下文中验证音乐播放与偏好、首页手动切换、四站完整 3D 预览、强制教学与刷新恢复、真实 12 秒烧制（不直接写入火候结果）、鼓风与暂停、失败后自由重试、重播资源释放、中英文、触屏和减少动态效果。截图输出到 `qa/journey-update/`。先启动 `npm run dev`；可用 `GAME_URL` 指定服务地址。

## GitHub Pages 部署

线上地址：https://bmc-gordon0921.github.io/Porcelain_Workshop/

推送到 `main` 后，GitHub Actions 自动安装依赖、运行逻辑测试、构建并部署 `dist/`。也可在 Actions 的 “Deploy to GitHub Pages” 流程中手动运行。仓库 Settings → Pages 使用 GitHub Actions 作为部署来源。

Vite 使用相对资源路径，地图和参考图片也跟随构建基础路径，支持 GitHub Pages 的项目子目录。`qa/`、`shots/` 和 `dist/` 不提交到源码仓库。
